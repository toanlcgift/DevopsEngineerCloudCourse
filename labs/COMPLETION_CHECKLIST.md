# Instructor / Learner Completion Checklist

- [ ] Can describe a DevOps feedback loop and distinguish IaaS, PaaS, and SaaS responsibilities.
- [ ] Can create, inspect, merge, and undo Git changes using a chosen branching strategy.
- [ ] Can explain a Jenkins pipeline stage and diagnose a failing build.
- [ ] Can build and run a container, define a Compose service, and troubleshoot a Minikube rollout.
- [ ] Can review Terraform plans and run an idempotent Ansible playbook.
- [ ] Can query Prometheus and build a basic Grafana view.
- [ ] Can use AWS, GCP, and Azure storage simulators and distinguish their limited emulation from real cloud behavior and identity controls.
- [ ] Can run code and image scans, assess findings, and document a verified deployment and rollback.
