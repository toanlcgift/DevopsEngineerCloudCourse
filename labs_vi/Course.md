Tổng quan:
Khóa học trang bị cho học viên tư duy, quy trình và bộ công cụ hiện đại để triển khai, tự động hóa và vận hành hệ thống phần mềm trên nền tảng điện toán đám mây.

## Mục tiêu khóa học

- **Nắm vững nền tảng:** Hiểu tổng quan về văn hóa DevOps và chiến lược triển khai ứng dụng trên Cloud.
- **Thành thạo công cụ CI/CD:** Sử dụng Git, Jenkins, Docker và Kubernetes để xây dựng pipeline tích hợp và triển khai liên tục (CI/CD).
- **Tự động hóa hạ tầng (IaC):** Quản lý và khởi tạo hạ tầng tự động bằng Terraform và Ansible.
- **Monitoring & tối ưu:** Thiết lập hệ thống monitoring, thu thập log toàn diện bằng Prometheus và Grafana.
- **Bảo mật hệ thống (DevSecOps):** Tích hợp các bước bảo mật tự động vào quy trình DevSecOps thực tế trên Cloud.

**Thời lượng:** 5 ngày

## Nội dung khóa học

### 1. Tổng quan DevOps & Cloud Computing

- Văn hóa DevOps và Software Development Lifecycle (Agile/DevOps)
- Tổng quan hạ tầng Cloud (AWS/Azure/GCP) và các mô hình IaaS, PaaS, SaaS

### 2. Source Code Management & CI/CD Automation

- Version control nâng cao với Git (Git Flow, Trunk-based Development)
- Xây dựng pipeline tự động hóa Build/Test/Deploy với Jenkins (Jenkinsfile)

### 3. Application Packaging & Orchestration (Containerization)

- Đóng gói ứng dụng gọn nhẹ, tối ưu với Docker và Docker Compose
- Quản trị, scale và điều phối ứng dụng quy mô lớn với Kubernetes (K8s)

### 4. Infrastructure as Code (IaC) & System Monitoring

- Khởi tạo và quản lý hạ tầng dưới dạng code bằng Terraform
- Quản lý configuration và triển khai tự động trên nhiều máy bằng Ansible
- Theo dõi metrics, cấu hình alert và quản lý log tập trung với Prometheus và Grafana

### 5. Thực hành DevSecOps trên Cloud (Capstone Project)

- Tích hợp bảo mật tự động theo hướng Shift Left Security: quét lỗ hổng code (SAST) và Container Image
- Quản lý IAM và Secret an toàn trên Cloud
